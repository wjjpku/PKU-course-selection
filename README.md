# PKU Course Selection

北大选课本地工作台：课程查询与时间预览、独立刷课任务、最近 100 条轮询日志、SQLite 任务持久化，以及 macOS 后台服务入口。

最新已发布版本 **0.1.0** · [版本说明](releases/v0.1.0.md) · [未发布改动与更新记录](CHANGELOG.md) · [快速使用](docs/usage.md) · [文档导航](docs/README.md) · [贡献指南](CONTRIBUTING.md)

这是源码项目，不是安装后即可自动选课的程序。已验证环境为 macOS / Python 3.12；其他平台尚未完整验证。前端不需要安装 Node.js 或打包，Node.js 仅用于开发测试。

## 本地启动

需要 Python 3.12。进入项目目录后：

```sh
python3.12 -m venv .venv-ocr
.venv-ocr/bin/pip install -r requirements-local.txt
cp -n skj包/config.sample.ini skj包/config.ini
.venv-ocr/bin/python skj包/main.py
```

上面的复制配置步骤**仅用于首次安装**，已有配置时跳过，避免覆盖账号和任务设置。更新前先停止任务，保留 `skj包/config.ini` 与 `skj包/data/`，再安装依赖并重启。

Windows 可将虚拟环境命令改为 `.venv-ocr\Scripts\python.exe`，安装依赖使用 `.venv-ocr\Scripts\python.exe -m pip install -r requirements-local.txt`，首次复制配置使用 PowerShell 的 `Copy-Item`。macOS 后台服务入口不能用于 Windows。

访问 <http://127.0.0.1:7074/>，不要直接打开 HTML 文件。启动默认仅开启本地工作台，登录、读取课程及启动选课任务均由用户操作。遵守学校选课规则及开放时间；学校返回禁止访问提示时不要继续重试。

## 数据与安全

- 账号保存在本机 `skj包/config.ini`，不会提交 Git。
- 任务和最近日志保存在 `skj包/data/workbench.sqlite3`，不会上传；重启恢复任务但不自动选课。
- 登录 Cookie 不持久化。课程缓存不代表实时名额。
- 请求串行，正常轮询间隔由用户设置；网络异常保留退避等待。
- 不提供退课或自动换课操作。
- 浏览器会话、截图、数据库、运行日志和个人任务备份均排除在仓库之外。

`service_runner.py` 可作为 macOS 后台托管入口，需按本机实际路径配置 LaunchAgent。它防止闲置睡眠，不保证关机、合盖或断网时继续工作。

## 一键查课与 CSV

CSV 的「课程类型」按学校查询入口定义（例如从专业课入口查到即标为专业课），「查询入口值」保留请求中的原始分类标识；「课程类别」仍保留学校返回的原值，如必修、限选、任选，不用于替代入口类型。同一课程从多个入口查到时分别保留，避免去重丢失入口信息。无法读取入口名称时明确标为未识别，不猜测。旧 CSV 未记录入口，不能可靠追补，需要重新查询生成新版 CSV；以上分类也不代表个人培养方案的学分认定。

在「课程查询」页展开「更新课程库 / 下载原始 CSV」，点击「更新课程库」。程序读取学校当前查询表单，遍历课程分类、院系范围及分页，合并完全相同的记录。不同年级、专业、教师、班号或时间的记录不会按课程号简单合并。

该功能只导出当前学期、当前账号可查询列表中的文本字段，不跟随课程大纲或选课操作链接，不保证包含未对账号开放的课程。学校提供哪些列就保留哪些列，另附查询时间与完整性标记。名额只是查询时的快照，年级或考试时间空缺不代表没有限制或冲突。

全量导出专用请求间隔为 4 秒，与刷课间隔设置独立；单次最多 300 个请求。刷课任务运行时禁止开始全量查询。可随时停止；停止、访问限制、分页异常或请求失败均保留已读部分，但明确标为部分 CSV，绝不标为完整。

生成的 CSV 存放在 `skj包/data/exports/`，不会提交 Git。可在页面下载最近一次结果，旧文件仍保存在该目录。UTF-8 BOM 编码兼容 Excel；若需要保留课程号的前导零，请通过 Excel「从文本/CSV」导入并将课程号列设为文本。为避免公式执行风险，以公式符号开头的单元格会加单引号。

## 更方便地查询课程

1. **同步一次**：登录后更新课程库。之后的关键词搜索、筛选、翻页与导出都在本地进行，无需反复访问学校；刷课任务运行时也能查询已有课程库。
2. **组合筛选**：课程类型按查询入口，院系和年级支持多选，学分精确筛选；多个关键词用空格分隔。筛选条件与页码按账号范围保存在本机浏览器，刷新后恢复。也可以切回「已读取选课页」，明确区分全量库与单页数据。
3. **看卡片**：直接显示时间、余量快照、P/NP，以及与哪门已选课或课程篮课程的哪段时间冲突。缺少时间的课仍显示，未知不等于无冲突；考试同半天仅提示待核对。
4. **加入课程篮**：只保存本地意向，不提交选课。查看原始信息或预览课表不改变课程篮。缺少必要字段的记录不能创建任务。
5. **导出筛选结果**：导出当前全部匹配记录，而非仅当前页。跨入口合并显示的卡片在 CSV 中保留各入口原始行。旧 CSV 缺少入口时标为「入口未记录」，不推断类型；新查询才能补齐。

课程库来自当前账号可见的列表，不代表全校所有课程；面向年级、院系与课程类型也不保证个人可选资格。创建刷课任务不代表该课程已加入学校选课计划；任务仍按当前选课阶段与学校返回列表查找，找不到会记录原因，不会自动改学校计划。

数据库保存最近导出记录和最近可用课程库，CSV 文件作为快照。更新失败且没有读到记录时，保留上一次可用库，重启后仍可查询。旧缓存不冒充实时数据；更新失败或停止会注明部分结果。重新载入本地数据不向学校发请求。账号切换后如提示范围不一致，先确认没有运行任务，再重启后端载入对应账号数据。

## 测试与贡献

需要安装 Python 依赖和 Node.js。推荐在项目根目录执行：

```sh
.venv-ocr/bin/python scripts/check.py
```

此入口自动复制示例配置到临时目录，并禁用 Python 测试中的网络连接，不要求填写真实账号，不读写个人配置、不启动选课。包含后端回归、查询筛选与 CSV 安全、冲突解释和前端语法检查。贡献方式见 [CONTRIBUTING.md](CONTRIBUTING.md)。
