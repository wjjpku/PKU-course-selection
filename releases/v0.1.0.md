# v0.1.0 · 本地课程查询与刷课工作台

这是 PKU Course Selection 的首个源码发布。支持本地课程查询、课程篮、时间冲突说明、独立刷课任务和 SQLite 持久化。

## 主要功能

- 一键读取当前账号可查询的课程列表，按分类与分页导出 CSV。
- 本地组合筛选：关键词、查询入口类型、院系、学分、年级；刷新恢复条件与页码。
- 卡片直接说明与哪门已选课或课程篮课程冲突，列出节次、教学周；保留无时间课程。
- 导出全部筛选结果，跨查询入口保留来源，不将学校“任选”等类别冒充入口类型。
- 独立任务参数和最近 100 条轮询日志；失败原因可见，旧日志自动淘汰。
- 数据库恢复任务但不自动选课；更新失败且没有新数据时保留最近可用课程库。
- 本地 OCR、浅色/深色/跟随系统主题、移动端布局，以及不需要真实账号的离线测试入口。

## 安装

下载源码并解压，按根目录 README 创建 Python 3.12 虚拟环境、安装 `requirements-local.txt`，首次使用时复制 `skj包/config.sample.ini` 为 `skj包/config.ini`。

运行 `.venv-ocr/bin/python skj包/main.py`，浏览器访问 `http://127.0.0.1:7074/`，不要直接打开 HTML 文件。Windows 请按 README 使用对应的 Python 路径。

发布包是源码，不是独立可执行程序，不包含虚拟环境或预装依赖。

## 已有用户升级

- 先保存工作并手动停止运行中的刷课任务，再更新代码、安装依赖并重启后端。
- 保留本机 `skj包/config.ini`、`skj包/data/`；不要用示例配置覆盖自己的配置。数据库会自动补充所需表。
- 重启后任务保持停止状态，登录会话需重新建立。
- 旧 CSV 没有查询入口的记录会显示“入口未记录”，重新更新课程库才能补齐。

## 验证与边界

在 macOS / Python 3.12 上通过 46 项 Python 测试、3 组前端逻辑检查及语法检查；隔离浏览器验证了查询、条件恢复、分页、冲突说明、课程篮和 CSV 导出。复现命令：`.venv-ocr/bin/python scripts/check.py`。

课程范围受当前账号与学期限制；不包含课程大纲等详情页。余量是快照，时间缺失不代表无冲突，年级与类型不保证个人可选资格。真实选课兼容性需以学校返回为准，本次发布没有执行真实选课或退课验证。

账号密码仅保存在使用者本机；发布包不含真实账号配置、数据库、个人课程 CSV、Cookie 或日志。不提供退课或自动换课操作。请遵守学校规定及开放时段。
