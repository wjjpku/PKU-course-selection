# 选课工作台使用说明

先按 [README](../README.md) 安装依赖并创建本机配置。macOS 可双击根目录的「启动工作台.command」，或在项目根目录运行后端，访问 <http://127.0.0.1:7074/>。不要直接打开 HTML 文件，也不要在同一端口重复启动服务。本文命令及数据路径均相对项目根目录。

## 找课

1. 首次使用先保存账号并登录；密码不会回显。已有本地课程库时，不登录也能查询缓存。
2. 展开「更新课程库 / 下载原始 CSV」，点击「更新课程库」。这一步只读，不加入学校选课计划、不提交选课。运行刷课任务期间不能进行全量更新。
3. 输入关键词，按查询入口类型、院系、学分和年级组合筛选。搜索、分页与导出只读本地数据，刷新页面可恢复条件。
4. 课程卡片直接列出上课时间、余量快照和冲突对象。先「刷新已选课表」再核对，旧缓存和未知时间不能当作实时、无冲突的依据。
5. 「导出筛选结果」包含全部匹配记录，不只是当前页；「下载原始 CSV」保留学校原字段和查询来源。

## 创建与查看刷课任务

1. 点击「加入课程篮」保存本地意向；「预览课表」不改变课程篮。
2. 在「课程篮 · 确认后创建任务」核对课程，在新任务参数中调整频率、页码、超时和规则。
3. 创建任务后进入「刷课」目录，核对任务配置并明确启动。每个任务独立循环，账号请求仍串行。
4. 在任务卡片查看每轮检查的结果和未选中原因；最近 100 条日志自动保留，超量淘汰最旧记录。
5. 暂停、继续、停止只控制本地任务，不退课。正在进行的网络请求需结束或超时后才能响应停止。

查询库里有课程，不代表它已在学校的选课计划中；任务仍需在学校当前操作页面找到对应课程。找不到、无空位、时段未开放等情况会记录原因，不自动改变学校计划。选课结果以学校最终记录为准。

## 保存、重启与自检

- 账号密码以明文保存在本机 `app/config.ini`，页面保存时文件权限限制为当前用户读写；不要上传或分享。
- SQLite 保存任务和历史信息，重启恢复为未运行，不自动选课；Cookie 不持久化，需重新登录。
- 更新课程库失败且无新结果时，保留最近可用的本地库。旧 CSV 未记录查询入口时，重新更新才能补齐类型。
- 「系统调试」使用独立进程做离线检查，不执行真实选退课。开发者可运行 `scripts/check.py`，使用临时示例配置完成回归。
- 本地 OCR 测试使用历史图片；通过不等于学校在线验证码一定识别成功。

请遵守学校选课规则和开放时间。本工具不提供退课或自动换课操作。
