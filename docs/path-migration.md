# 应用目录迁移

当前源码使用 `app/`，替代历史目录 `skj包/`。Python 包仍叫 `autoelective`，依赖版本及目录内部结构不变。

- 启动：在项目根目录执行 `.venv-ocr/bin/python app/main.py`。
- macOS 快捷启动、`service_runner.py`、离线检查和展示构建已更新到新路径。
- 本机配置：`app/config.ini`；任务、缓存与导出：`app/data/`。这些文件仍被 Git 忽略。
- 历史 `v0.1.0` 发布说明保留该版本实际使用的旧路径，不代表当前分支路径。

## 已有安装升级

先停止任务和后端，再更新代码。Git 不会自动搬迁被忽略的私人文件：请将旧目录中的 `config.ini`、`data/`、`cache/`、`log/` 等本机内容完整保留并迁移至 `app/` 的对应位置。数据库必须连同可能存在的 `-wal`、`-shm` 文件一起处理；不要在运行时复制或合并数据库。目标已存在时先核对，禁止直接覆盖。不要把示例配置覆盖到真实配置。

检查自定义服务、编辑器任务和个人脚本中是否写死旧路径，然后以新入口启动。重启后任务保持停止，需手动启动；不会退课。

本次当前机器采用整体目录重命名，私人文件未复制或重建；为保持已有后端的旧路径引用，暂留忽略的本机符号链接 `skj包 -> app`。它不进入 Git，干净克隆不需要它。以后后端已通过新入口重启、且没有旧路径依赖时可移除该链接；不要递归删除链接目标。
