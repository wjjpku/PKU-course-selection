# 前端改进来源与边界

返回 [文档导航](README.md)。

本次借鉴公开项目的交互思路，在现有工作台内独立实现，没有安装或复制第三方用户脚本，也没有引入第三方账号服务。

- [PKU Art](https://github.com/zhuozhiyongde/PKU-Art)：参考统一视觉与主题切换思路；上游采用 GPL-3.0。本项目没有复制其样式或脚本。
- [CoSel](https://github.com/Chen571428/CoSel)：参考课程列表与课表对照的选课方式；上游采用 MIT。本次课表及冲突检查为独立实现。
- [PKUElectiveHelper](https://github.com/goudanZ1/PKUElectiveHelper)：参考课程检索和状态提示；未引入其云端验证码服务。

## 本次实现

进一步借鉴 PKU Art 的查询条件记忆、切换分类保留关键词、分页与内容分离、P/NP 与余量突出展示，以及跟随系统主题的思路；均在本项目内独立实现。参考源码版本：`adc8cdcd98daf0b4cdcc858a0c55ebd622d41dd7` 的 `src/utils.js`、`src/theme.js` 和 `src/css/electiveCourseQuery.css`。没有注入用户脚本或引入外部账号、下载、选退课处理。

新增本地 CSV 课程库读取接口及纯前端组合查询；课程卡片显示冲突对象、节次和教学周，不增加冲突分类筛选。无时间记录始终保留，跨查询入口保留来源，缺少入口的旧数据不从学校课程类别反推。

课程卡展示课程号、教师、学分和原始时间信息；支持课表预览、手动切换教学周、单双周及教学周交集冲突检查、课程篮已知学分合计和深浅主题。

“预览课表”不加入任务，也不提交选课。冲突提示不自动删除课程、不换课、不退课。信息缺失时显示待核对；同一天同一半天的考试只提示可能冲突。教学周需手动选择，不推断校历。

## 使用与验证边界

新课程元数据需要新版后端读取课程后才能显示。旧缓存缺少字段时不得据此认定没有冲突。后端更新需要安全重启；重启会丢失内存登录会话，任务会从 SQLite 恢复为未运行，不自动选课。不重启有活动任务的服务。

所有本地测试使用构造数据，不执行真实选课或退课。实际学校页面兼容性仍需以只读获取的数据核对。
